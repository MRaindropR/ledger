# 电脑端账本

`index.html` 是生成文件，和原生 App 共用金额、数据转换、版本同步与冲突处理代码。保留原网页的布局和图标，移除旧版整份 JSON 云同步。正式账本存在 IndexedDB，只有成功提交后才显示“已保存”。同一浏览器的多个标签页使用事务串行更新。

构建：在 `mobile` 目录执行 `npm ci`，然后 `npm run build:desktop`。GitHub Actions 会上传生成 HTML。`legacy-ui.html` 是经过删除旧云端凭据的界面输入，不是可独立使用的账本。

原桌面文件与仓库根目录 HTML 未替换。新页面首次加载只迁移同源旧 localStorage 数据；换地址不会自动读取另一地址的账本，需用旧页面导出文件后导入。新导出的 Excel 增加完整账本 JSON 工作表，保留投资成本为空、溢缴款、币种及预算设置。

导入前自动在 IndexedDB 保存恢复点，最多保留 3 份；恢复点只含账本，不含会话。备份页可恢复这些副本，但恢复操作会同步到已连接的云端账本。清除浏览器数据会丢失本机恢复点，不能替代导出文件。

手机与电脑须登录同一 Supabase 用户并连接同一账本。上线前需按 `docs/sync-setup.md` 配置新数据库表与邮箱登录；代码和本地测试通过不代表线上双端验证完成。不要把管理员密钥放进 HTML。
